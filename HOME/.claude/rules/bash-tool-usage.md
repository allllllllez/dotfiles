# Bash Tool 実行規律

## 作業ディレクトリの明示

Bashツールの作業ディレクトリはコマンド間で持続する。複数のリポジトリ・ディレクトリを
跨いで作業するときは、各コマンドの先頭で対象ディレクトリへ明示的に `cd` する。
直前のコマンド呼び出しの `cwd` が残っている前提でコマンドを書かない。

複数のリポジトリに同種の操作（ブランチ作成、状態確認など）を連続して行うときは特に注意する。
1回でも「意図しないディレクトリで実行された」ことに気づいたら、その場の再実行だけで済ませず、
以降の同種コマンド全てに明示的な `cd` を付け直す。

## バックグラウンドタスクを sleep で待たない

`run_in_background` で起動したコマンドの完了を、`sleep N; tail <output>` で
待たない。完了すると通知が届いて自動的に再開するため、待ちは不要である。

`sleep` で待つと前景の Bash が数分間ブロックされ、その間 Cru からは何も
起きていないように見える。直前の出力が誤解を招く内容（permission denied など）
だった場合、Cru が不要な対処を始める。

起動したらそのターンを終える。次にやることがあるなら、待たずにそれを進める。

例外は、ハーネスが追跡できない外部の状態を待つときだけ（CI の実行、
デプロイの反映など）。その場合も、対象の状態が変わる速度に合わせた間隔を選ぶ。
