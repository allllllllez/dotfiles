# stop-slop

## 概要

書いた文章を「AIが書いた感」から抜き出すためのチェックリストとスコアリング。除去対象は、論点を増やさず「ちゃんと書いている感」だけを付ける言い回しと、内容より演出を優先する構造パターン。

である調の文章に対する禁止フレーズと Before/After は [[writing-technical]] の「LLMっぽい表現の禁止」節がすでに担当している。ですます調の「枠を宣言する語」「ダッシュ・中黒の禁止」「演出の抑制」は [[writing-structure]] が担当している。この skill はそれらを重複させず、文体を問わず使える統合チェックリストと、既存2つの rules がまだ拾っていない構造パターンだけを新規に扱う。

文章を見直すときは、まず既存2つの rules の点検リストを適用し、その後で以下の新規項目を確認する。

## 既存 rules が担当する項目（ここでは詳述しない）

- 予告と総括、正面から系、空虚な形容・空虚な動詞、接続の型の連打、弱い緩和の濫用 → [[writing-technical]]
- ダッシュ・中黒の禁止、決め台詞の演出抑制、枠を宣言する語（「見る」「扱う」で済ませない） → [[writing-structure]]

## 新規に扱う項目

### 1. 二項対立の芝居

「Aではない。Bだ。」のように、否定を演出として使い、Bを直接言う前に一度Aを立てて壊す構文。

悪い例：「原因は個人の能力不足ではない。仕組みの不備だ。」
良い例：「原因は仕組みの不備にある。」

否定してから言い直すこと自体は、根拠を示す限り誠実な譲歩として必要な場面もある（[[writing-technical]] の「AではなくBと否定するときは、否定の根拠を一文添える」が担当）。ここで禁止するのは、否定の根拠を示さずに対比の型だけを流用する演出。

### 2. 列挙的お立て台詞

「〜ではない。〜でもない。〜だ。」のように三段階否定してから答えを言う構文。答えを最初から言う。

悪い例：「これは仕様ではない。バグでもない。設計判断の結果だ。」
良い例：「これは設計判断の結果だ。」

### 3. 無生物主語の人間的動作

無生物や抽象概念を主語にして、人間の行為であるかのような動詞を使う構文。行為者を特定したくないときにこの構文へ逃げやすい。

悪い例：「議論がその場で解決策に姿を変えた。」
良い例：「議論を重ねて、その場でチームが解決策を決めた。」

行為者が本当に不特定なら、一般的な語（「チーム」「担当者」など）に置き換える。誰の行為でもない自然現象（「気温が上がった」など）は対象外。

### 4. 距離を置いた語り

個別の事実を、当事者から距離を置いた一般化文で処理する構文。「〜する人は多い」「〜が起こりがちだ」のように、誰の話かを曖昧にしたまま済ませる。

悪い例：「こうした見落としは起こりがちだ。」
良い例：「レビュー担当者がこの見落としを繰り返していた。」

統計的傾向として正しい一般論を述べる場合は対象外。個別の事実を一般化文に逃がしている場合だけを指す。

### 5. リズムの単調さ

文の長さが揃いすぎている構文。特に、同じ構文の短文を3つ以上連続させる。

悪い例：「レビューをした。指摘を書いた。修正を依頼した。」
良い例：「レビューをして指摘を書き、修正を依頼した。」

短文の連打自体が悪いわけではなく、単調さが悪い。長短を混ぜる。

## Quick Checks

文章を書き終えたら、次を順に確認する。

- [ ] 二項対立の芝居（「AではなくB」の型で、根拠を示さず対比だけを演出していないか）
- [ ] 列挙的お立て台詞（否定を2つ以上重ねてから答えを言っていないか）
- [ ] 無生物主語が人間の行為を担っていないか
- [ ] 個別の事実を「〜する人は多い」で一般化して逃げていないか
- [ ] 同じ構文の短文が3つ以上連続していないか
- [ ] [[writing-technical]] の禁止フレーズ一覧（である調の場合）に該当する語がないか
- [ ] [[writing-structure]] のダッシュ・中黒・枠を宣言する語の禁止に該当していないか

## スコアリング

5軸で1〜10点、合計35点未満なら要修正。

| 観点 | 問い |
|---|---|
| 直接性 | 結論を最初に言っているか、演出のために遠回りしていないか |
| リズム | 文の長さが混ざっているか |
| 行為者の明示 | 誰がやったかが文から読み取れるか |
| 具体性 | 個別の事実で語っているか、一般化で逃げていないか |
| 削れる語の有無 | 二項対立や三段否定などの演出的な構文が残っていないか |
