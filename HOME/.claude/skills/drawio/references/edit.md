# 既存の図を直す

既存の .drawio を直すよう頼まれたら、描き直さずに、そのファイルを直す。

1. ファイルを読む。`<diagram>` の中身が XML ではなく英数字の塊なら、draw.io で圧縮して保存された図なので、`drawio -x -f xml -o 展開後.drawio 元.drawio` で展開してから読む
2. 既存の図は `<mxfile>` と `<diagram>` に包まれていることが多い。外枠はそのまま残し、中の `<mxGraphModel>` だけを直す。`<diagram>` が複数あるのはページが複数ある図で、依頼されたページだけを直す。どのページか分からなければ、ページの名前を挙げて聞く
3. 依頼されたところだけを変える。既存のセルの id、座標、スタイルはそのまま残す。足すアイコンや線は、この Skill の決まりに従って置く。元の図がこの Skill の決まりと違う描き方をしていても、依頼に無ければ直さず、気づいたことを最後に伝えるだけにする
4. 足すものが収まらなければ、周りのアイコンを動かしてよい。動かしたものは最後に伝える
5. 保存先の指定が無ければ、元のファイルに上書きする。展開して読んだ図は、展開した形で保存されることも伝える
6. 新しく描くときと同じように PNG に書き出して確かめる
